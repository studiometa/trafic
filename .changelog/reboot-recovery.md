### Fixed

- **Agent**: Previews come back after a server reboot without a manual `ddev start`. Docker now starts `ddev-router` again at boot: the router compose override `/home/ddev/.ddev/router-compose.trafic.yaml` exists on every server and sets `restart: unless-stopped` over the `restart: "no"` of DDEV's template. Before, the router stayed down, no request reached the agent, and the waiting page could not start any project. Migration `0023__router_restart_policy` writes the override on existing servers (with the DNS provider credentials where `[tls]` has some) and gives the running router the policy with `docker update`, without a restart
- **Agent**: When the service starts, it sets to `stopped` the projects that its database marks `running` but that `ddev list` does not show up. After a reboot, the idle sweep and `max_running_projects` counted projects whose containers were gone
